# Operating Systems Lab Manual (Python)

This repository contains my **Operating Systems Lab Manual** for B.Tech CSE 3rd Year.

It includes Python programs demonstrating important Operating System concepts and algorithms.

## Topics Covered

- Linux System Calls and Process Creation
- Thread Creation and Management
- CPU Scheduling Algorithms (FCFS, SJF, Priority, Round Robin)
- Producer-Consumer Problem
- Readers-Writers Problem
- Dining Philosophers Problem
- Banker's Algorithm
- Memory Allocation (First Fit, Best Fit, Worst Fit)
- Page Replacement Algorithms (FIFO, LRU, Optimal)
- Disk Scheduling Algorithms (FCFS, SSTF, SCAN, C-SCAN)
- File Allocation Methods

## Language

- Python

## Purpose

This repository is created for learning, practicing, and understanding Operating Systems laboratory concepts.
